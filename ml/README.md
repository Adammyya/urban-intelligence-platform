# Machine Learning Engine

Dedicated environment for Machine Learning research, model training, and inference serving.

## Purpose
Data engineering, feature extraction, training predictive models (congestion, accidents), and exposing a fast inference API.

## Technologies
Python, FastAPI, Scikit-learn, XGBoost, TensorFlow, PyTorch.

## Scalability
Separation of training and inference allows deploying lightweight inference containers while running heavy training jobs on GPU clusters.
